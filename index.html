Estamos trasladando nuestros servicios a una nueva infraestructura en la nube, diseñada para ofrecer mayor rendimiento, disponibilidad y seguridad. Durante este proceso, algunos servicios permanecerán temporalmente fuera de línea.

¿Qué está ocurriendo?

Estamos realizando una migración de infraestructura que incluye el traslado de aplicaciones, sistemas y servicios a nuestro nuevo entorno de alojamiento.

Este proceso requiere detener temporalmente algunos componentes para realizar las tareas de migración, configuración y verificación de funcionamiento.
